# Drop v1.11.3-drop.1

## สิ่งที่ตรวจพบและแก้ไข

- กลับจากพักหน้าจอแล้วไม่เชื่อมต่อ: เลือก visibility event ผิดและตรวจชื่อ property แทนค่า เพิ่มการตรวจ socket ค้างและรองรับ pageshow
- การจำ pair: รอ transaction เขียนสำเร็จก่อนแจ้งผล ปิด connection ฐานข้อมูลหลังใช้งาน และอัปเดตข้อมูลใน transaction เดียวเพื่อไม่ให้ชื่อกับ auto-accept ทับกัน
- โหลดหน้าเว็บค้าง: ให้ตัวโหลดไฟล์ส่งต่อ error ตั้งลำดับการรัน script และเพิ่ม timeout/retry สำหรับ config
- ห้องค้างหลัง disconnect: แก้การตรวจสมาชิก array การออกจากทุกห้อง และกัน socket เก่าลบสมาชิกที่เชื่อมต่อใหม่
- ความปลอดภัย: ตรวจสมาชิกก่อนส่งต่อข้อความ ลบห้อง หรือเปลี่ยน secret; ตรวจรูปแบบรหัสห้อง; แสดงชื่ออุปกรณ์ด้วย textContent
- Dependency: อัปเดต Express และ ws ภายใน major เดิม พร้อมปรับ npm/Bun lockfile
- UI: เอาพื้นหลัง ขอบ และเงาการ์ดรอบอุปกรณ์ที่เชื่อมต่อออก ไม่แก้ตัว iPhone หรือ floating dock
- ธีม: ติดตามการเปลี่ยนธีมระบบในโหมด auto และซิงก์การเลือกข้ามแท็บ
- Service worker: ไม่ cache config แม้มี query, ไม่ fetch ซ้ำเพื่อเก็บ cache, ส่งต่อ error ของ cache ได้ และลบเฉพาะ cache ของแอปนี้

## การตรวจสอบ

- `npm test`: regression tests 8 รายการ
- `npm audit --omit=dev`: ไม่พบช่องโหว่ใน dependency ที่ตรวจ
- Chrome headless: ใช้สอง browser contexts แยกกัน พร้อม viewport มือถือ 390 × 844
- Pair ทั้งสองฝั่ง บันทึก pair รีโหลด ตัดและต่อเน็ต กลับมาด้วย pageshow แล้วส่งข้อความภาษาไทยและไฟล์ ตรวจ cache ของ service worker เวอร์ชันใหม่
- ตรวจการอัปเดตชื่อพร้อม auto-accept การเปลี่ยนธีมระบบและธีมที่ผู้ใช้เลือก และพื้นหลังอุปกรณ์ที่เชื่อมต่อ
- ไม่ได้ทดสอบบน iPhone/Safari เครื่องจริง จึงยังต้องลองพักหน้าจอและกลับมาใช้บนเครื่องจริงหลัง deploy

การจำ pair ยังขึ้นอยู่กับพื้นที่เก็บข้อมูลของเบราว์เซอร์ หากผู้ใช้ล้างข้อมูลเว็บไซต์หรือเบราว์เซอร์ลบข้อมูลทิ้ง ต้อง pair ใหม่ การเปลี่ยน origin เช่น domain, protocol หรือ port ก็ใช้ข้อมูลคนละชุดกัน

## v1.11.3-drop.2

แก้พื้นหลังตอนสลับธีมในแอปที่เพิ่มจาก Safari: ซิงก์สี html/body, color-scheme และ theme-color พร้อมกัน เอา transition ของสีพื้นหลังออกเพื่อให้เปลี่ยนทันที และตรวจธีมปัจจุบันอีกครั้งเมื่อกลับเข้าแอป ไม่แก้ markup ของ iPhone หรือ floating dock

ตรวจด้วย WebKit และ Chrome ใน viewport iPhone: สลับมืด/สว่างหลายรอบโดยไม่รีโหลด ตรวจสีพื้นหลังและ wallpaper, เปลี่ยนธีมระบบในโหมด auto และเรียก pageshow เพื่อทดสอบการกลับเข้าแอป ผ่านทั้งหมด พร้อม regression tests 9 รายการ ทั้งนี้ WebKit บน Linux ไม่ใช่การทดสอบแอป Home Screen บน iPhone เครื่องจริง
